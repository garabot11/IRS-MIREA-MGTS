# Управляемый участник испытания Unitree G1

Для пересечения маршрута Go2 используется модель G1 с 12 приводами ног и закреплённым верхом корпуса. Геометрия, массы, инерция, кинематика и предобученный регулятор ходьбы взяты из одной ревизии репозитория Unitree. Здесь сохранены оригинальный MJCF, 27 требуемых STL, конфигурация и численные параметры обученной модели. Контрольные суммы исходных файлов и преобразованных весов доступны в манифесте. [Ревизия Unitree](https://github.com/unitreerobotics/unitree_rl_gym/tree/276801e46c5d433564f24658bac64f254b7d2d4b), [лицензия](UNITREE-LICENSE), [манифест](provenance.json).

Политика LSTM получает ориентацию относительно силы тяжести, угловую скорость, команду скорости корпуса, измерения 12 суставов, прошлое действие и фазу шага. Она выдаёт целевые суставные положения с частотой 50 Гц. Регуляторы PD передают моменты в симулятор с частотой 500 Гц. Отдельный сценарный контроллер G1 задаёт ему переход на 1,8 м вдоль начального направления. Через две секунды он начинает движение и снижает команду по мере подхода к цели. Положение корпуса устанавливается при начальном размещении. Дальнейшее движение создают моменты и реальные контакты виртуальных стоп с физическим полом. Собака получает данные от собственного лидара. [Контроллер и загрузчик G1](../../humanoid_actor.py), [оригинальный пример MuJoCo](https://github.com/unitreerobotics/unitree_rl_gym/blob/276801e46c5d433564f24658bac64f254b7d2d4b/deploy/deploy_mujoco/deploy_mujoco.py).

На сетке из официального обхода G1 прошёл 1,818 м за испытание длительностью 15 с. Чистое горизонтальное перемещение за последнюю секунду составило 1,0 см. Минимальная высота таза составила 0,764 м. Каждая стопа оказывалась единственной опорой более чем на 3200 подшагов физики. Контактов остальных частей тела с полом не зарегистрировано. Эта проверка выполнялась со стоящей Go2. Взаимный объезд проверяется в интегрированном прогоне сценария с гуманоидом. [Отчёт о ходьбе](physics-check.json).

Проверка воспроизводится из корня проекта в среде физического симулятора.

```bash
OPENBLAS_NUM_THREADS=1 python3 -m hackathon_solution.v2.sim_assets.humanoid.verify \
  --map hackathon_solution/v2/results/map
```

В среде с NumPy и PyTorch можно отдельно проверить экспорт. На 200 последовательных входах полная рекуррентная история сохранена. Максимальное абсолютное отклонение любого выхода от оригинального TorchScript равно 0,0000194. [Результат сравнения](policy-check.json).

```bash
curl -fLsS https://raw.githubusercontent.com/unitreerobotics/unitree_rl_gym/276801e46c5d433564f24658bac64f254b7d2d4b/deploy/pre_train/g1/motion.pt -o /tmp/unitree-g1-motion.pt
OPENBLAS_NUM_THREADS=1 python3 -m hackathon_solution.v2.sim_assets.humanoid.verify \
  --original-policy /tmp/unitree-g1-motion.pt
```
